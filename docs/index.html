How we measured
  • All of it comes from oneclick-cli bench, which is in the download, plus the app's own memory use measured on the same PC. Run it and you get your own numbers; one laptop is not every laptop.
  • Scans are read-only. Developer junk counts real files and skips links. Sizes use binary units, like Windows Explorer.
  • The app's memory is the private memory Windows reports for its processes: the window after a full scan, the tray watch after 10 seconds.
  • Focus test: one hashing task, timed alone, next to 2 busy programs per CPU thread, and next to the same programs after Focus mode's efficiency mode was applied to them. Each is the median of 5 runs. Only programs the test started were slowed, and the power mode was not changed.

What it does

One click

You see the list, then you click

A scan takes about two seconds and gives your PC a health score. The Optimise button lists every change it will make before you press it. Untick anything you want to keep.

Optimise does
  • Close programs that sit idle: Gradle and Kotlin daemons, adb, dev servers nobody is using
  • Delete temp files older than 7 days, and crash dumps
  • Stop apps that open at sign-in for no reason
  • Set always-on background services to start only when needed
It never does
  • Clean the registry, or "boost" RAM by flushing caches
  • Close a Windows process or anything you are using
  • Follow a link out of a folder it cleans
  • Change anything without showing it to you first
Developer junk

Old projects, cleared safely

It finds node_modules, Rust target, Gradle build, Python virtual environments, .NET bin/obj and the big package caches on every drive, with sizes and when each project last changed.

  • A folder counts only when its project file sits next to it, and that is checked again right before deleting.
  • Projects nobody changed for 30 days are ticked. Package caches never are.
  • Windows, Program Files and AppData are never searched.
Autopilot Focus mode

Clean-ups on their own, full power on demand

Autopilot runs daily or weekly once your PC has been idle for 5 minutes. It deletes old temp files and closes build daemons that sat idle for 30 minutes with nothing connected to them. Mark anything "never close" and it stays put.

Focus mode puts busy background programs into Windows' efficiency mode and switches the power mode to Best performance. Turn it off and everything goes back.

Tray watch

Out of the way until it matters

The tray icon changes colour with memory pressure. Click it for your biggest apps, what one click will do, and a Focus mode switch. It uses about 2.5 MB of memory.

It speaks up only when memory has been almost full for two minutes, when dev tools sit idle, or when a new version is ready, and it waits while you present or play full-screen.
